# 横切处理法（T01–T07）

处理法不是风格，是**叠层**：给任何基础风格加一层材质或行为。规则：0–2 个；与基础风格不同族；每个处理法落地时只动「这一层」的东西，不侵占基础风格的版式骨架。

## T01 · Analog × Digital

**做什么**：现代结构上出现人的痕迹——手写批注、便利贴、扫描纸、铅笔线、胶片颗粒。
**怎么叠**：基座保持数字规整（S04/S07/S10 最佳宿主）；人痕稀疏（≤20% 区域）、非对称、有动机：「这个实验结果是不是有问题？」式具体内容的手写旁批、一张贴歪的黄色便利贴、一条铅笔圈住的数据点。手写字体：LXGW 文楷 / 手写体 Caveat / 拍照的真手写。
**红线**：手写内容必须是真实批注语义（问题、更正、签名），不是装饰性假笔记（§1.1/§1.2.3）；便利贴最多两张。
**网页实现**：便签用 rotate(±2°) + 轻阴影；手写可 SVG path 描边动画（reduced-motion 降级为静态）。

## T02 · Texture / Tactile

**做什么**：让屏幕看起来可以摸——纸颗粒、布纹、油墨、浮雕、扫描噪点。
**怎么叠**：给底色/大色块换材质（纸白 → 带纤维的纸白；纯黑 → 布纹黑）；油墨感 = 元素边缘轻微不均（feTurbulence displacement 0.5–1px）；一处压凹/压凸（inset 阴影成对）。S01/S02/S03/S09 的天然伴侣。
**红线**：颗粒覆盖全局时 ≤6% 不透明度且仅 fixed 伪元素（性能见 design-taste-frontend §6.E）；纹理不许进正文区降低可读性；「Texture Check」是让材质替底色说话，不是加一层脏滤镜。
**印刷实现**：直接选纸（亚粉/莱妮/牛皮），工艺 > 模拟。

## T03 · Kinetic Typography

**做什么**：字体本身在运动、变形——F→FU→FUTU→FUTURE 逐字揭示、拉伸、碎裂、避让光标。
**怎么叠**：只在**标题/关键词**层动，正文静止；一个页面 1–2 个 kinetic 时刻（hero 一个、章节转场一个封顶）；运动有语义（揭示=内容渐次呈现；碎裂=概念被打破）。
**红线**：无限循环的 kinetic 字幕条全页 ≤1；reduced-motion 全降级为静态排版；正文/表格/表单字禁动。
**网页实现**：CSS scroll-driven animations（`animation-timeline: view()`）优先，GSAP ScrollTrigger 做 pin/scrub（`start: "top top"`），骨架抄 design-taste-frontend §5.A/5.B；禁 `window.addEventListener('scroll')`。

## T04 · Experimental Typography

**做什么**：字即图形——排版本身成为主视觉。
**怎么叠**：选一句真实核心文案，让它承担画面 60%+ 的视觉重量：字号 200–400pt、负字距 -0.04em、词内换行错位、竖排横排混用（CJK 天然优势：竖排一句压横排段落）、字图互嵌（图嵌进字的负空间）。S01/S02/R01 的放大器。
**红线**：实验只发生在这一句上，其余文字全部退回功能性排版；核心文案必须真实且短（≤12 字/词），编不出好句子就别用这招；可读性底线——认得出是那句话。
**印刷实现**：海报/封面主场；字出血裁切留 5mm。

## T05 · Reality Warp / Surreal

**做什么**：摄影真实 × 不可能空间——书架弯成环、影子变成 UI、墙融化、字从建筑里穿出。
**怎么叠**：底片必须**真实摄影感**（光影正确、透视合理），只扭曲一处空间逻辑；扭曲点即视觉锚点，其余构图正常。S07/品牌官网最佳宿主。
**红线**：一图一个 warp 点；全图融化=没有锚点；生成图里出现无意义文字（AI 乱码字）必须修复或裁掉。
**实现**：生图（prompt 强调 `physically accurate lighting, single impossible element`）；网页可 Three.js displacement mesh 或 SVG filter，但一个场景一件。

## T06 · Digital Scrapbook

**做什么**：截图、贴纸、便签、鼠标箭头——Z 世代的桌面拼贴。
**怎么叠**：基座是干净页面（S10/Bento 化的）；上面「贴」元素：带系统窗口 chrome 的截图（真截图）、贴纸（带白边 1–2px + 微旋转 ±3°）、一个遗留的鼠标光标图标指着关键处、聊天气泡片段。R02/R09 的年轻化剂。
**红线**：截图必须真实（真产品真对话，假截图=§1.1 重灾区）；贴纸 ≤5 张；光标 1 个；贴的动作要有轻微不一致（旋转角度、遮挡层次），完美对齐的拼贴是假的。
**网页实现**：贴纸 hover 可拖（彩蛋）；移动端收起一半贴纸防拥挤。

## T07 · Notes App Chic

**做什么**：像备忘录/草稿/工作区——「让你觉得在偷看设计师电脑」。
**怎么叠**：容器模仿笔记应用：圆角窗口 + 顶栏（日期、三按钮）或纯纸感列表；内容用 checkbox 列表（`[x] launch  [ ] behave`）、随手小标题、`IMG_7281.JPG` / `final_final_v3.psd` 式真实文件名痕迹、一句自言自语。S10/S04 的反转剂，作品集/personal 站利器。
**红线**：文件名与待办必须是该项目**真实**的文件与进展（真文件名 > 编造，编的必须是显然幽默且不冒充事实）；不做完整假 UI（一条工具栏即可，做全套=假截图）；笔记腔 ≠ 错字满篇，语法基本正确只留口语感。
**网页实现**：等宽或手写体混排；`contenteditable` 留一处真可编辑是彩蛋级加分。
